# 🚀 GenAI AWS Practice

Welcome to **GenAI AWS Practice** – a hands-on project led by *Ravi Teja*, focused on harnessing the power of **AWS Foundation Models** to build smart, scalable Generative AI applications. Whether you're exploring Retrieval-Augmented Generation (RAG) or building real-world AI tools, this repo will help you navigate through it all.

---

## 📌 Overview

This repository demonstrates how to use **Amazon Bedrock**, **LangChain**, and supporting AWS tools to build practical Generative AI solutions. From chatbots to intelligent resume matchers, the goal is to learn, experiment, and create production-grade systems powered by **foundation models**.

---

## 🌐 Use Cases Explored

- 🤖 Chatbots using Bedrock's Claude or Titan models  
- 📄 PDF/Doc resume parsing and job description matching  
- 🔍 Retrieval-Augmented Generation (RAG) pipelines  
- 🧠 Embedding and semantic search over custom datasets  
- 🛠️ Custom frontends using Streamlit / PyQt5  

---

## 🧱 Tech Stack

| Component        | Technology                    |
|------------------|-------------------------------|
| Backend          | Python, Flask / FastAPI       |
| GenAI Layer      | Amazon Bedrock, LangChain     |
| Embeddings       | Amazon Titan / Bedrock APIs   |
| Document Parsing | PyMuPDF, pdfminer, textract   |
| Frontend (opt.)  | Streamlit / PyQt5             |
| Vector DB (opt.) | FAISS or in-memory storage    |
| Cloud Services   | AWS IAM, S3, Bedrock, Lambda  |
